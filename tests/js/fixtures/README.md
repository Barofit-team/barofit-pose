# Python 참조 결과

두 파일 모두 합성 관절·각도 입력이다. 원본 영상이나 사용자 관절 기록은 포함하지 않는다.

- `squat-python-parity.json`: 팀원의 `feat/squat-colab` 커밋 `54c56ab77c27d9e4b40314bc945519cca645607a`에 있는 Python 엔진으로 만든 319프레임 상태·회차 결과와 좌표 계산 5개 사례. 원본 엔진 해시를 파일에 기록했다.
- `bird-dog-python-parity.json.gz`: 로컬 Python 버드독 v0.3 참조 구현에서 생성한 10개 시퀀스·798프레임. 정상, 다리 들기, 몸통 이동, 가림, 좌우 반전, 누락, 시간 간격, 영상 크기, 낮은 신뢰도, 카메라 기울기를 포함한다. 참조·추출기 해시와 입력·기대 결과를 파일 안에 기록했다.

버드독 Python 연구 코드는 이번 웹 공유 변경에 포함하지 않는다. 고정 결과를 사용하므로 CI가 다른 미커밋 코드나 Python 환경에 의존하지 않는다.

버드독 파일은 표준 gzip으로 압축한 UTF-8 JSON이다. Node의 `gunzipSync` 또는 일반 gzip 도구로 열 수 있다. 규칙을 바꿀 때 기존 기대 결과를 덮어쓰기 전에 변경 근거와 별도 검증 결과를 검토한다.

이 테스트는 Python과 JS의 구현 일치를 확인한다. 실제 운동 자세 정확도를 증명하지 않는다.
