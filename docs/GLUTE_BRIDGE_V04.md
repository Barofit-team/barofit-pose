# 글루트 브리지 하강 템포 보완 · 2026-10-23

## 근거와 기준
NASM Floor Bridge는 통제된 하강을 안내하고 갑작스럽거나 통제되지 않은 동작을 오류로 제시합니다. ACE McGill Bridge도 천천히 통제해 내려오도록 설명합니다. 자료에는 0.6초·65°/초·105°/초라는 오류 임계값은 없습니다. 이 수치는 개발 영상 비교로 정한 공학적 후보값입니다.

- https://www.nasm.org/resource-center/exercise-library/floor-bridge
- https://www.acefitness.org/resources/pros/expert-articles/5901/effective-exercises-to-target-the-glutes/

기존 전체 하강 0.6초 미만 AND 평균 65°/초 초과 규칙을 유지했습니다. 여기에 최고점 이후 0.20~0.35초 구간에서 15° 이상 내려가며 속도가 105°/초를 초과하는 경우를 추가했습니다. 최소 4개 샘플, 구간 내 역방향 변화 누적 2° 이하, 한 샘플이 전체 하강의 65%를 넘게 차지하지 않는 조건을 사용합니다. 기존 평활화된 어깨–골반–무릎 각도와 연속성 검사를 사용합니다.

개발 자료의 정상 시범 11회에서 구간 최고 속도는 약 98°/초 이하였습니다. 105°/초는 정상 최댓값과 빠른 동작의 겹침을 고려한 보수적 후보입니다. 정상 표본이 작으므로 일반화된 안전 경계가 아닙니다. 근육 제어력을 직접 측정하는 것도 아닙니다.

경고는 기존과 같이 회차 완료 시 확정되며 하강 도중 즉시 음성 경고를 시작하는 변경은 없습니다. 결과 metrics.loweringEvidence에 판단 이유와 빠른 구간의 시각·각속도·각도 변화량을 추가했습니다.
