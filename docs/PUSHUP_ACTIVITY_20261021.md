# 푸시업 수행 상태 구분 — 2026-10-21

## 적용 범위

MediaPipe와 MoveNet 푸시업 실행 경로에 동일한 `PushupActivityGate`를 적용했다. 모델별 관절 신뢰도 기준(MediaPipe0.5, MoveNet0.3)은 유지한다. 실제 왕복 검출·작은 움직임 제외·자세 평가 기준과 공통 결과 규격은 변경하지 않았다.

일반 푸시업의 수행 상태를 구분하는 모듈이며, 앱의 세트 종료를 자동으로 호출하지 않는다. 무릎을 바닥에 대고 수행하는 변형 푸시업은 이번 적용 범위가 아니다.

## 상태와 동작

| 상태 | 처리 |
|---|---|
| 준비 | 기존 방식대로 필요한 관절이 안정적으로 관측되는 쪽을 선택 |
| active | 기존 카운트와 자세 평가 진행 |
| exit_candidate | 무릎을 크게 접거나 몸을 세우는 신호가 나타나면 즉시 카운트·피드백 보류 |
| outside_exercise | 종료 신호가0.25초 지속되면 진행 중인 왕복 기록 초기화. 이미 누적한 횟수 유지 |
| resuming | 다리를 편 수행 형태가0.25초 유지되면 새 왕복부터 다시 측정 |

단발성 좌표 오류가 발생하면 의심 프레임을 평가에서 결측 처리하고 후보 동작은 보존한다. 종료가 확정되지 않은 상태에서 곧바로 자세가 회복되면 기존 카운터의 시간 단절 기준 내에서 이어간다. 관측되지 않은 좌표를 채워 넣거나 종료 구간에서 횟수를 소급 추가하지 않는다.

## 사용 기준

- 종료 후보: 관측된 골반–무릎–발목 각도가120° 미만, 또는 어깨–발목의 화면 수평 성분 비율이0.5 미만.
- 복귀 확인: 무릎 각도150° 이상, 수평 성분 비율0.5 이상을0.25초 유지.
- 기존 설정 파일에 있던 `pipeline.v3` 값을 연결했다. 실험용 공학적 기준이며 임상적 자세 기준이 아니다.
- 골반 처짐·올라감 자체는 종료 조건으로 사용하지 않는다.
- 종료가 관측되기 전 무릎 좌표가 없다는 이유만으로 종료를 추정하지 않는다. 기존 필수 관절 검사도 계속 적용한다.
- 종료가 확인된 뒤에는 무릎이 안 보이는 상태로 다시 측정을 시작하지 않는다.

상태는 기존 `frame.result`의 `details.diagnostics.activity`에 기록한다. 최상위 `phase`와 JSON Schema는 변경하지 않았다. `activity.changed` 이벤트와 `motion.reset` 사유를 함께 기록한다.

## 동일 입력 재생 비교

| 영상 | MediaPipe 이전→이후 | MoveNet0.3 이전→이후 |
|---|---:|---:|
| P2 good |12→12|12→12|
| P2 bad |12→12|13→13|
| P5 good |9→7|6→6|
| P5 bad |6→6|8→7|

P5 good에서 MediaPipe의17.533초·18.533초 종료 동작 카운트2개가 제거됐다. P5 bad에서는 MoveNet의18.4초 종료 동작 카운트1개가 제거됐다. 다른 회차의 검출 시점은 유지됐다.

P5 good의 마지막 운동 시도는 MediaPipe7회, MoveNet6회로 여전히 다르다. 기존 관절 추출과 복귀량 판정 차이를 그대로 유지한 결과다. 초반 작은 시도 및 마지막 불완전한 복귀를 새로 세도록 기준을 낮추지 않았다.

P2 bad의 MoveNet6.733초에서 무릎 좌표가 한 프레임 튀는 장면도 확인했다. 종료 후보로 보류한 뒤 즉시 회복시켜 기존13회를 유지했다. 종료 확정 전 후보 기록을 보존하는 이유다.

이 표는 출력 비교와 특정 오류 수정 검증이며, 전체 정확도를 의미하지 않는다.

## 검증·재현

- 단위·회귀 검사71개 통과.
- 기존 왕복·자세 판정 엔진과 설정, 다른 운동 모듈, 공통 반환 코드의 해시 유지.
- 수정 전과 같은 모델 좌표·프레임·타임스탬프를 재생.
- 프레임 및 세트 결과를 기존v2 JSON Schema로 검사.
- 영상의 길이·프레임 디코딩 및 종료 장면을 확인.

```text
node examples/compare_pushup_activity.mjs POSE_COMPARISON_DIR MOVENET_FIX_DIR OUTPUT_DIR
```

기본 `PushupAnalyzer`와 선택형 `MoveNetPushupAnalyzer`에 적용된다. 이전에 설치한 APK나 다른 위치에 복사한 런타임은 소스를 갱신·빌드해야 반영된다.
