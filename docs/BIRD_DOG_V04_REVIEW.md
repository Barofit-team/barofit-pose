# 버드독 판정 수정 및 영상 검토

2026-10-21 · v0.3 → v0.4 · Python / JavaScript

## 결과
기존 6개 출처의 11개 구간을 다시 분석하고, 신규 YouTube 시범 2개를 추가했다. 자연스러운 체중 이동을 몸통 오류로 보던 문제를 줄였고, 복귀 단계에 고정돼 유지 자세를 놓치는 오류를 수정했다. 모든 오류를 해결한 상태는 아니다.

## 원인과 수정
| 문제 | 확인한 원인 | 수정 |
|---|---|---|
| 정상에서 BODY_MOVEMENT | 앞뒤 이동까지 합산, 뻗는 어깨 사용, 지지점이 손목/무릎 사이에서 변경 | 유지 단계의 지지 팔 쪽 어깨·골반을 같은 손목 기준으로 비교. 몸통 선에 수직인 이동과 기울기만 경고에 사용 |
| 유지 자세인데 판정하지 않음 | 잠깐의 좌표 역행으로 returning에 진입하면 준비로 돌아오기 전까지 고정 | 복귀 중 다시 뻗는 움직임을 포착하면 reaching → holding으로 재진입 |
| 허리 과신전 누락 | 어깨·골반·발목 선은 척추 곡률을 측정하지 못함 | 허리 오류로 확대 해석하지 않음. 미검출 사례 보존 |
| 비스듬한 구도의 정상 경고 | 투영된 각도, 무릎 굽힘, 관절 흔들림이 함께 반영 | 이번 변경으로 미해결. 임계값을 낮추거나 구간을 정상으로 덮어쓰지 않음 |

몸통 평가를 유지 단계로 제한했으므로 전환 단계의 문제는 이 규칙으로 평가하지 않는다. 이는 범위 축소이며 전 동작의 정확도 개선과 구분한다. `unknown`과 `not_applicable`은 정상으로 집계하지 않는다.

## 같은 구간끼리 비교
이전·수정 규칙 모두 평가할 수 있었던 **동일한 시간**의 경고를 비교했다. 숫자는 경고 지속 시간이며 정확도·재현율이 아니다. 전문가가 설명한 시범 의도와 육안 검토를 사용했고 임상 정답 라벨은 없다.

| 영상 | 공통 평가 시간 | 같은 구간의 몸통 경고: 이전 → 수정 | 수정 후 전체 평가 가능 / 검토 시간 |
|---|---:|---:|---:|
| E3 정상 시범 | 7.74초 | 5.47 → 0.00초 | 7.74 / 18.00초 |
| NASM 정상 시범 | 3.59초 | 1.92 → 0.00초 | 3.59 / 8.00초 |
| PostureDoc 오류 시범 | 9.17초 | 8.08 → 7.58초 | 9.17 / 9.50초 |
| Hinge Health 정상 시범 · 신규 | 22.87초 | 0.00 → 0.00초 | 22.87 / 56.00초 |
| Titan 정상 지도 장면 · 남은 경고 | 4.67초 | 4.20 → 2.13초 | 4.67 / 21.00초 |
| Squat University 오류 시범 · 미검출 | 9.00초 | 0.53 → 0.00초 | 9.00 / 9.00초 |
| Cornerstone 정상 시범 · 판정 범위 부족 | 1.27초 | 1.27 → 0.00초 | 1.27 / 15.00초 |

PostureDoc 오류 경고는 유지됐지만 Squat University 오류는 계속 놓친다. Titan의 정상 지도 장면에도 경고가 남는다. Hinge의 10.53초→0초 감소는 모두 판정 범위 변경에 의한 것이므로 공통 유지 구간의 성능 향상으로 주장하지 않는다.

## 신규 YouTube 확인
- Hinge Health: 원본 12–75초 중 18–74초 검토. 물리치료 시범, 전신·단독 인물. 다리 평가 가능 구간에서는 경고가 없었으나 몸통은 가림/기준 초기화 때문에 평가하지 못한 시간도 존재한다.
- Cornerstone Physiotherapy: 원본 48–57초, 63–69초 검토. 운동자는 추적했으나 비스듬한 구도와 가림으로 평가 범위가 부족하다. 정상 경고 0초를 검증 성공으로 세지 않는다.
- Chris Duffin 영상은 인물 둘·팔다리 잘림·변형 동작 때문에 이번 비교에 제외했다. HealthFit 영상은 버드독과 donkey kick이 섞여 있어 정상/오류 구간을 임의로 붙이지 않았다.
- 원본 장면과 자막을 먼저 확인하고 검토 구간을 기록했다. Cornerstone 결과를 보고 단계 전환 오류를 수정했으므로 이번 신규 자료까지 포함해 탐색·개발 검증이며 독립 최종 시험이 아니다.

## 유지한 설정과 남은 과제
- 다리 정렬: 어깨→골반 연장선과 골반→발목의 부호 있는 각도, +20° 초과 0.25초. 무릎 굽힘의 영향이 있으므로 임계값 추가 조정 전 오류 유형을 나눠야 한다.
- 몸통: 준비 몸통 길이 대비 수직 이동 12% 또는 기울기 변화 12° 초과 0.25초.
- 위 숫자는 공학적 실험값이다. ACE 등 자료는 동작 정의의 근거이며 이 수치를 검증한 근거가 아니다.
- 다음 우선순위는 유지 단계 누락·기준 초기화 감소, 구도별 오경고 검증이다. 허리 곡률/골반 회전은 별도의 관측 방법이 필요하다.
- Python 버드독 20개 및 전체 JS 30개 테스트 통과. 합성 798프레임의 Python/JS 상태·수치 일치 확인. 테스트 통과가 운동 정확도 검증을 뜻하지 않는다.

## 영상과 재현 자료
`index.html`에서 수정 전후를 나란히 볼 수 있다. 좌측 v0.3, 우측 v0.4. 새 영상은 H.264이며 시작·중간·끝 디코딩을 확인했다.
`comparison_coverage.json`에 경고 시간, 공통 평가 시간, unknown/대상 외 시간을 저장했다. `results/*/frames.jsonl`은 프레임별 결과, `frozen_config.json`은 규칙과 코드 해시다. `adapter_before.py`는 비교한 이전 Python 규칙이다.
코드는 `barofit-pose/analysis/bird_dog/adapter.py`, `runtime/bird_dog/analyzer.js`에 반영했다. 배포 사이트와 APK를 새로 배포한 것은 아니다.
