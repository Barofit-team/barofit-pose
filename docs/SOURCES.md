# 출처와 데이터 관리

- 관절 추출: [Google MediaPipe Pose Landmarker](https://ai.google.dev/edge/mediapipe/solutions/vision/pose_landmarker).
- 판정 코드: 바로핏 프로젝트에서 개발한 푸시업·플랭크 로직.
- 원본 코드별 복사 경로와 SHA는 `source-manifest.json`에 기록했습니다. 경로는 기존 작업 폴더에 대한 상대 경로입니다.
- Python 푸시업 기준 JSON은 기존 무결성 검증을 유지하기 위해 선택 샘플의 상대 경로/익명 subject ID/기준 산출 기록을 포함한 원본을 보존했습니다. 영상이나 관절 원본은 포함하지 않습니다.
- 플랭크: `multi_rule.py`의 import 두 곳만 패키지 상대 경로로 바꾸고, `metric()` 함수를 UI 파일에서 분리했습니다. 판정 수식은 유지했습니다.
- Android 연동 예제는 기존 APK 소스의 라이브러리 부분입니다. 앱 화면·개인 로그·서명 키·모델 바이너리는 제외했습니다.
- 합성 테스트 관절은 코드 검증을 위해 생성한 좌표입니다. 실제 사람의 정답 라벨이나 성능 검증 데이터가 아닙니다.

원본 영상·모델의 재배포 권한은 이 저장소가 부여하지 않습니다. 팀 코드의 외부 라이선스도 아직 지정하지 않았습니다.
데이터를 공유할 때는 별도 저장 위치와 이용 조건을 확인합니다.
