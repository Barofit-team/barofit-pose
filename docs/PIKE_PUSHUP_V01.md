# 파이크 푸시업 — 측면 v0.1

기준일: 2026-10-27 · 엔진: `pike-pushup-0.1.0`

## 동작과 근거

바닥에서 역V 자세를 만든 뒤 팔꿈치를 굽혀 머리를 손보다 앞쪽으로 내리고, 위로 밀어 시작 자세로 복귀하는 동작입니다. 측면 전신 촬영을 사용합니다. 무릎의 약간 굽힘은 오류로 분류하지 않습니다.

- [NASM Pike Push-Up](https://www.nasm.org/resource-center/exercise-library/pike-push-up): 역V 자세, 머리 하강, 골반 유지, 제어된 움직임.
- [Nick-E Pike Pushup](https://nick-e.com/pikepushup/): 손보다 앞쪽으로 머리 이동, 앞으로 밀기와 위로 밀기의 차이, 무릎 굽힘 허용. 정상·오류 시범이 구분되어 있습니다.
- [PureGym Pike Push-Ups](https://www.puregym.com/exercises/chest/press-up/pike-push-ups/): 역V 자세와 제어된 하강·복귀.

아래 각도·거리·시간 임계값은 문헌의 정답 수치가 아니라, 측면 영상 측정값으로 정한 프로토타입 공학적 기준입니다.

## 판정 항목

| 항목 / 코드 | 측정 방법 | 현재 기준 |
|---|---|---|
| 역V 유지 / `PIKE_HIPS_LOW` | 어깨–골반–무릎 각도 | 동작 중 112° 초과가 0.2초 지속 |
| 머리 하강 경로 / `HEAD_PATH_BACK` | 손목보다 앞쪽으로 이동한 코 좌표를 몸통 길이로 정규화 | 최저점 부근 중앙값이 0.15 미만. 코 좌표 부족 시 미평가 |
| 위로 밀어 복귀 / `PRESS_OUT` | 복귀 시 골반–어깨–손목 각도 | 복귀 구간 중앙값이 105° 미만 |

손목–발목 방향을 기준으로 머리의 전후 방향을 정하므로 좌우 반전과 작은 카메라 기울기를 보정합니다. 픽셀 종횡비를 반영합니다. 관절 신뢰도가 확보된 한쪽을 선택합니다.

## 횟수와 실시간 피드백

준비 → 하강 → 상승 → 복귀를 완료하면 1회입니다. 준비 팔꿈치 145° 이상, 하강 변화 20° 이상, 반전 5° 이상, 복귀는 145°와 시작 각도−12° 중 큰 값 이상을 사용합니다. 유효 주기는 0.6~20초입니다. 자세 경고가 있어도 완료한 주기는 카운트합니다.

정지·미세 움직임·영상 시작 전 이미 내려간 부분 동작은 새 회차로 세지 않습니다. 프레임 누락·좌우 전환·일시정지·큰 시간 간격에서는 진행 중인 주기를 끊습니다. 준비 자세 조건을 벗어나면 판정을 중단합니다. 종료 후 일어서기 차단은 합성 관절 입력으로 확인했습니다.

현재 구간 판정과 최근 완료 회차 피드백을 구분합니다. 최근 회차는 2.2초 표시합니다. 머리 경로 실시간 경고는 하강 중에만 평가하여 정상 상승 과정에서 발생하던 오경고를 제거했습니다.

## 실제 영상 검토

| 구분 | 검토 범위 | 결과 |
|---|---|---|
| 정상 | 7구간, 9회, 3명 | 9회 카운트, 실시간·회차 경고 0 |
| 머리 경로 오류 | 2구간, 4회 | 4회 카운트, 4회 해당 경고 |
| 복귀 방향 오류 | 2구간, 3회 | 3회 카운트, 3회 해당 경고 |
| 골반 낮음 | 1구간, 2회 | 2회 카운트, 2회 해당 경고 |

정상·오류 합계 12구간, 18회, 4명의 제한된 표본입니다. 같은 제작자의 여러 구간은 독립된 사람으로 세지 않습니다. 기준을 조정한 자료를 다시 검증한 결과이며 독립 평가 정확도가 아닙니다. 분할 화면의 Chris 골반·복귀 비교는 낮은 패럴렛을 사용한 보조 시범입니다.

추가로 준비 자세 전환, 체중 이동 오류, 허리 과신전, 시작·끝이 잘린 구간을 확인했습니다. 전체 실행 18구간 중 겹치는 구간과 부분 동작은 위 집계에서 제외했습니다.

## 오경고 보완과 측정 분포

| 측정 | 정상 표본 | 대상 오류 표본 | 반영 |
|---|---|---|---|
| 회차 최대 어깨–골반–무릎 각도 | 약 74~100° | 약 114~120° | 112° 기준, 지속 시간 적용 |
| 최저점 머리 전진 / 몸통 길이 | 약 0.18~0.62 | 약 −0.33~0.07 | 0.15 기준 |
| 복귀 골반–어깨–손목 각도 | 약 112~152° | 약 92~104° | 105° 기준 |

PureGym 정상 시범은 무릎 굽힘 때문에 어깨–골반–발목 각도가 커졌습니다. 골반 기준점을 무릎으로 변경해 하퇴 움직임의 영향을 줄였습니다. 복귀 기준을 시작 자세 대비 감소량으로 설정하는 방법은 정상 시범도 경고하여 제외했습니다. 절대 복귀 각도는 정상·오류 측정 범위를 비교해 적용했습니다. 프레임별 수치가 경계에 가까운 영상은 촬영 각도에 영향을 받습니다.

## 공통 결과 v2

`PikePushupAnalyzer`는 `pushFrame`, `breakContinuity`, `summary`, `finish`를 제공합니다. 기존 실시간·세트 종료 엔벨로프를 사용하고 운동 분기만 추가했습니다.

| 정보 | 의미 |
|---|---|
| exercise | `pike_pushup` |
| count | 완료된 하강–상승 주기. 기준: `completed_pike_lower_raise_attempt` |
| holdSeconds | null — 유지 운동이 아님 |
| observedSeconds | 연속으로 자세를 관측한 시간. 운동 효과·정상 유지 시간과 다름 |
| 항목별 준수율 | 회차 기준 `repetition`, 0~100. 미평가는 분모에서 제외, 평가 0회면 null |
| 회차 metrics | 시작·최저점·복귀 시간, 하강·상승 시간, 팔꿈치 변화량, 골반 각도, 머리 전진, 복귀 각도 |
| 템포 | 단계 경과 시간이며 단계 내 멈춤을 포함. 속도 경고는 제공하지 않음 |

허리 중립·팔꿈치 벌어짐·발끝 하중은 `not_supported`로 구분합니다. 머리 경로 경고를 팔꿈치 벌어짐으로 단정하지 않습니다. 머리의 바닥 접촉, 척추 곡률, 근육 활성은 관절 좌표로 판정하지 않습니다.

## 실행 및 확인

```sh
node examples/pike-pushup.mjs path/to/landmarks.jsonl path/to/results
npm test
```

Python의 기존 MediaPipe 추출 결과를 JS 엔진에 전달합니다. 별도 Python 판정 복사본은 없습니다. 입력과 출력 JSONL, 세트 종료 JSON을 저장합니다. 출처·사용 구간은 `analysis/pike_pushup/source_manifest.json`, 구간별 검토 결과는 `analysis/pike_pushup/review_results.json`에 기록했습니다. 원본 영상과 모델 파일은 저장소에 포함하지 않습니다. 명시적 재배포 허가가 없는 영상은 로컬 검토에만 사용했습니다.

전체 JS 테스트 116개 통과, 실시간 1,717개·세트 종료 18개 결과의 v2 JSON Schema 검증을 통과했습니다.
