# 파이크 푸시업 단계·경로 판정 보완

기준일: 2026-10-28 · 엔진 pike-pushup-0.2.0 · 1차 프로토타입 검증 완료

측면 전신 촬영에서 머리를 손보다 앞쪽으로 내리고 위로 밀어 역V로 복귀하는 변형을 지원합니다. [입출력과 실행 방법](PIKE_PUSHUP_V01.md#공통-결과-v2)은 동일하며, 아래 단계·경로 판정이 기존 v0.1 판정을 대체합니다.

## 수정과 유지 범위

| 항목 | 수정 내용 |
|---|---|
| 골반 / PIKE_HIPS_LOW | 동작 중 최대 각도 하나 대신 준비 → 하강 → 상승 후반 → 복귀를 확인. 골반 각도가 열린 뒤 골반 상승과 역V 회복도 부족한 경우 경고 |
| 머리 / HEAD_PATH_BACK | 한 회 시작점에 고정한 좌표축·몸통 길이로 코의 전방 이동/하강량을 계산. 전완 기울기를 보조 근거로 사용 |
| 복귀 / PRESS_OUT | 상승 중 어깨와 골반의 동시 상승, 뒤로 돌아오는 이동량, 복귀 자세를 함께 확인. 도중의 오류를 마지막 자세 하나로 지우지 않음 |
| 카운트 | 기존 횟수 조건·발생 시각·동작 단계·선택 관절·관측 시간 유지 |
| 피드백 확정 | 카운트 후 최대 0.6초 복귀 확인. 다음 하강 시작 시 그전에 확정. 일시정지·추적 단절 시 이어 평가하지 않음 |
| 결과 규격 | 공통 v2 및 기존 키·단위 유지. 추가 측정은 운동별 metrics에만 저장 |

## 실제 재실행 결과

29구간, 3227개 프레임에서 수정 전후 횟수·동작 단계·카운트 이벤트가 전부 동일합니다. 중복·부분 동작을 제외한 주요 비교는 21구간 45회입니다. 같은 자료로 수정하고 재검증한 결과이며 독립 정확도가 아닙니다.

| 평가 | 수정 전 | 수정 후 |
|---|---:|---:|
| Tykato 정상의 골반 경고 | 6/6 | 0/6 |
| Tiffany 정상의 머리 경고 | 4/4 | 0/4 |
| Matt 머리 오류 검출 | 0/2 | 2/2 |
| Matt 복귀 오류 검출 | 1/2 | 2/2 |
| 전체 대상 머리 오류 검출 | 6/8 | 8/8 |
| 전체 대상 복귀 오류 검출 | 4/5 | 5/5 |
| 골반 낮음 검출 | 4/4 | 4/4 |

골반 낮음 4회에는 같은 Chris의 보조 영상 2회가 포함됩니다. 새로운 사람 4명 검증이라는 의미가 아닙니다.

출처 정상 28회 중 경고는 16 → 6회입니다. 남은 6회는 손 사이로 머리를 내리도록 안내하는 Trevor 영상입니다. 이 사례를 제외한 출처 정상 22회는 경고 10 → 0회입니다. 정상 영상의 실시간 오경고도 해당 사례들에서 사라졌습니다.

## 미평가와 한계

- 머리 경로가 이미 어긋난 회차는 같은 상승 형태를 별도의 복귀 오류로 중복 단정하지 않습니다. press_return은 unknown, 사유는 head_path_confound로 기록합니다.
- 주요 비교에서 복귀 미평가는 17회입니다. 머리 경로와의 혼동 14회, 관측된 상승량 부족 1회, 복귀 확정 전 추적 단절 2회입니다. 미평가는 준수율 분모에서 제외하며 정상으로 간주하지 않습니다.
- Trevor의 출처 설명과 현재 채택한 자세 방식의 차이는 그대로 남아 있습니다.
- 골반은 골반·어깨·무릎 관절의 화면상 형상입니다. 척추 곡률·근육 활성·팔꿈치 벌어짐을 판정한 결과가 아닙니다.
- 수치 한계는 검토한 영상에서 정한 공학적 기준이며 문헌에서 제시한 보편적 정답 각도가 아닙니다.

## 측정 기준

| 값 | 기준과 용도 |
|---|---|
| hipMaxDeg | 기존 112° 유지. 최대값 단독 오류 판정 제거 |
| headTravelRatio | 전방 이동/하강량. 0.8 미만이면서 최저점 전완 기울기 40° 초과일 때 수직 경로 근거. 손 근처 하강은 비율 1 미만을 함께 확인 |
| returnHipRiseRatio | 골반 상승/어깨 상승. 상승량 0.2 몸통 길이 이상에서 비율 0.5 미만 + 오버헤드 회복 부족을 결합 |
| 골반 회복 확인 | 상승 후반(팔꿈치 변화 50% 이상 회복), 상승 비율 0.9 미만 + 오버헤드 120° 미만을 결합. 단일 하강 각도 경고와 다름 |
| 지속/확정 | 경로 근거 0.1초, 실시간 표시 0.2초 지속. 카운트 후 최대 0.6초 확정 |

기존 bottomHeadForward, returnOverheadDeg, maxHipDeg의 뜻은 바꾸지 않았습니다. headTravelRatio, returnHipRiseRatio, settledHipDeg, settledOverheadDeg, pathAssessmentEndMs, pathAssessmentComplete, pressReturnAssessmentReason 등을 metrics에 추가했습니다.

## 검증

- 공통 JSON Schema: 실시간 3227개, 세트 종료 29개 통과.
- 공통 스키마 및 다른 운동 런타임 파일 변경 없음.
