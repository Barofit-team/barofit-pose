# 수퍼맨 종료 동작 보완·추가 검증 — 2026-10-26

## 수정 내용

팔을 뻗어 엎드린 운동 자세와 손·팔꿈치를 몸 아래로 가져와 지지하는 자세를 구분했습니다. 지지 자세 후보에서는 측정을 멈추며, 200ms 지속되면 진행 중인 동작을 폐기합니다. 이미 완료한 횟수는 보존합니다. 다시 팔을 뻗으면 400ms 동안 투영 신전값의 범위가 4° 이내로 안정된 뒤 새 기준점을 잡습니다.

지지 자세 후보는 골반–어깨–팔꿈치 각도 <110°, 손목이 몸통 축 아래로 몸통 길이의 0.25배 초과, 팔꿈치가 0.10배 초과인 조합입니다. 좌우 반전과 화면 회전을 고려한 몸통 축 기준 거리이며, 실제 바닥 접촉 판정은 아닙니다. 수치는 관측한 준비·종료 구간과 정상 동작을 비교한 공학적 설정입니다. 팔꿈치가 굽혀졌다는 이유만으로 운동을 종료하지 않습니다.

`metrics.activityStatus`에 `preparing`, `exercise_posture`, `support_or_exit`, `not_prone`를 기록합니다. 공통 실시간·세트 종료 v2 구조 및 카운트·준수율의 의미는 유지합니다. 기존 무릎 150°, 팔꿈치 145°, 속도 1.6초 기준은 변경하지 않았습니다. 허리 곡률·어깨 으쓱·다리 간격은 계속 미지원입니다.

## 팔 굽힘 검증 범위

양팔·양다리를 뻗는 표준 수퍼맨을 기준으로 합니다. [P]rehab의 Prone Superman 안내도 팔꿈치와 무릎을 편 채 수행하도록 설명하지만 145°라는 숫자를 제시하지는 않습니다.

새 정상 시범에서는 팔 경고가 발생하지 않았습니다. XHIT에서 팔꿈치가 몸통 쪽으로 잘못 추적되는 구간은 미평가로 유지되며, 합성 입력의 지속적인 팔 굽힘은 카운트를 유지하면서 경고를 냅니다.

검색한 팔 굽힘 후보에는 팔을 접는 수퍼맨 변형과 네발기기 동작이 많았습니다. 해당 영상을 표준 동작의 오류 정답으로 바꾸지 않았습니다. **실제 표준 수퍼맨의 팔 굽힘 오류에 대한 검출 성능은 아직 확인되지 않았습니다.** 현재 정상 표본·추적 실패·합성 입력 검증을 실제 오류 검증으로 합산하지 않습니다.

## 검증 기록

- 기존 5개 원본·16개 구간에 새 제작자 2개 영상과 기존 원본의 종료 포함 구간을 더해, 7개 원본·20개 구간을 전후 실행했습니다. 중복 구간을 독립 표본으로 세지 않습니다.
- Pure Physiotherapy와 종료 구간은 보완에 사용한 개발 표본입니다. AskDoctorJo만 이번 수정의 조정에 사용하지 않은 새 제작자 확인 표본입니다.
- 전체 자동 테스트 108개 통과. 수퍼맨 테스트 10개에 종료 자세, 재진입, 팔 가림, 팔 굽힘, 좌우 반전, 데이터 단절을 포함합니다.
- 수정 후 실시간 3,630프레임·세트 결과 20개 JSON Schema 검증 통과.
- 집계 기록: `analysis/superman/revision_20261026.json`. 원본 프레임·전후 분석 영상은 로컬 검증 산출물에 보관합니다.
- 촬영 구도 변화와 가려짐에 의한 미검출은 남아 있습니다. 영상 컷 자체를 검출하는 모듈은 아니며, 알려진 컷·중단에는 `breakContinuity()`를 사용합니다.
