# 스쿼트 / 새 운동 추가 방법

프론트 반환은 [실시간 결과 v2](realtime-contract-v2.md), 종료 집계는 [세트 결과 v2](result-contract-v2.md)에 맞춥니다. 운동별 항목 의미는 유지하고 현재 판정과 회차 평가를 구분합니다. 새 운동의 `measurementBasis`, 운동별 타입, JSON Schema 분기도 함께 정의합니다.

## 스쿼트 담당자가 할 일

1. 저장소를 clone하고 `feat/squat` 브랜치를 만듭니다.
2. Python 개발 코드를 `analysis/squat/`에 넣습니다. 로컬 절대경로·데이터 원본·노트북 출력은 제외합니다.
3. [입출력 규격](IO_CONTRACT.md)의 33개 관절 입력을 받도록 연결합니다. CSV/NPZ용 코드는 별도 실행 예제로 둡니다.
4. 판정 항목과 수식·임계값·필요 관절·지원 촬영 방향을 `docs/RULES.md`에 추가합니다.
5. 정상·오류·관절 누락·정지·중단/재개·역순 입력을 테스트하고 PR을 올립니다.
6. 앱 적용 시 JavaScript 구현을 `runtime/squat/`에 추가하고 `runtime/index.js`에서 export합니다.

스쿼트 JS 구현은 실시간·세트 종료 v2를 적용했습니다.
분석부터 PR로 공유해도 됩니다. 앱 이식 완료 여부는 README 상태표에 별도로 표시합니다.

## 맞출 인터페이스

앱용 클래스는 아래 메서드를 제공합니다.

| 메서드 | 역할 |
|---|---|
| `pushFrame({landmarks,width,height,timestampMs})` | 공통 프레임 결과 반환 |
| `breakContinuity(reason)` | 중단 구간을 넘어 움직임을 이어 세지 않도록 초기화. 완료 횟수는 유지 |
| `summary()` | 현재까지의 공통 세트 집계. 종료하지 않음 |
| `finish()` | 세트 결과 이벤트 반환. 반복 호출은 중복 이벤트를 만들지 않음 |

내부적으로 양쪽 관절이 필요하면 사용해도 됩니다. 푸시업처럼 무조건 한쪽만 쓰도록 강제하지 않습니다.
양쪽을 쓰는 종목은 `side: null`의 의미를 운동 문서에 명시하거나 규격 변경을 먼저 제안합니다.
운동별 필드는 `metrics` 또는 `details`의 운동별 정의에 추가합니다. 기존 키의 단위·의미를 바꾸면 규격 버전 변경이 필요합니다.

## 판정과 카운트는 별도

- 동작 시도에 대한 움직임 카운트를 자세 점수로 취소하지 않습니다.
- 정지/추적 흔들림을 카운트하지 않도록 운동별 움직임 조건을 둡니다.
- 필요한 관절이 없으면 unknown으로 처리합니다. 정상으로 채우지 않습니다.
- 오류 코드는 안정된 문자열로 두고 화면 문구/TTS는 분리합니다.
- 실시간 경고와 회차 전체 평가의 시간 범위를 구분합니다.

## PR에 적을 내용

- 무엇을 구현했는지, Python 분석인지 앱용 구현인지
- 지원 촬영 방향과 필요한 관절
- 판정 기준과 이전 버전에서 바뀐 점
- 테스트 명령과 결과
- 사람별 검증 범위, 아직 못 잡는 사례

임계값을 바꿨다면 기존 정상/오류 샘플 결과도 같이 비교합니다. 합성 테스트 통과를 실제 영상 정확도로 표현하지 않습니다.
타인의 영상이나 관절 데이터를 커밋하지 말고 공유 위치·샘플 ID로 연결합니다.

## 스쿼트 반환 규격 · 2026-10-28

- 실시간: `frame.result` v2. `items.trunk`와 `currentCodes`는 현재 몸통 판정입니다. 완료 회차의 깊이는 `lastRepetition.items.depth`에 반환하며 완료 프레임 이후에는 null입니다.
- 종료: `set.completed` v2의 `summary.items`. `depth`는 회차 기준, `trunk`는 시간 기준입니다.
- 준수율: `compliancePct` 0~100, 미평가는 분모 제외, 평가 데이터가 없으면 null입니다.
- 원본 회차 목록은 `summary.details.reps`, 출처와 실험 상태는 `details`에 보존합니다. 종료 `timestampMs`는 밀리초이며 내부 이벤트의 `t`는 기존 초 단위입니다.
- 판정 수식·임계값·카운트·시간 누적 조건은 유지했습니다.
