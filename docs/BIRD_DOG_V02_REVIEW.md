# 버드독 v0.2 · 수정 전후 검토

2026-10-20. MediaPipe Full 좌표 캐시와 영상 구간을 유지한 규칙 비교. 제품 정확도 검증은 아님.

## 수정 내용
- 무릎 펴기·정렬 등 기존 경고는 끄고 다리 높이·몸통 움직임 두 항목만 활성화.
- 다리별 준비 → 뻗기 → 유지 → 복귀 상태. 유지 구간만 다리 높이 평가, 복귀 제외.
- 몸통 움직임은 준비 기준점 이후 동작 전체에서 평가. 어깨/골반의 지지 손목 또는 무릎 대비 이동량과 몸통 선 기울기 변화를 측정.
- 먼 쪽 무릎이 가려져도 보이는 쪽의 안정된 준비 자세로 기준점 확보. 기준이 없거나 관절이 가려지면 unknown.
- 준비 기준은 움직임 비교용이며 정상 자세 인증이 아님. 0.4초 안정 구간을 사용하고 운동 중 계속 재설정하지 않음.
- 허리 곡률·축 방향 회전은 not_supported. 반복 카운트는 구현하지 않음.

## 실제 실행 결과

| 영상 | 기존 무릎 경고 | 새 다리 높이 경고 | 새 몸통 움직임 경고 |
|---|---:|---:|---:|
| Elite 오류 0–7.5초 | 1.33초 | 0.53초, 세 동작 모두 | 1.40초, 뒤 두 동작 |
| Elite 정상 10–17.6초 | 1.47초 | 0초 | 0초 |
| Point 혼합 20–53초 | 2.07초 | 0.47초 | 2.13초 |

수정 후 무릎 경고는 모두 비활성화. 기존 몸통 판정은 기준 미입력으로 평가되지 않았으므로 0경고와 구별한다.
정상 구간 몸통 평가 7.53초, 다리 높이 평가 1.47초. 오류 구간 몸통 평가 6.73초, 다리 높이 평가 1.33초.
나머지 다리 시간에는 준비·뻗기·복귀 등 평가 대상 밖인 구간이 포함된다. 경고 시간을 전체 운동의 오류율로 해석하지 않는다.
Elite 정상은 기준점 확보를 위해 원본 9–10초를 먼저 입력했다. 통계·영상 출력은 이전과 동일한 10–17.6초이며 미래 프레임은 사용하지 않았다.

## 남은 한계
- 첫 오류 동작의 몸통 경고는 누락. 그 순간의 표시 예시 이동량 11%는 후보 임계값 12%보다 작았다.
- 정상에서도 이동량 11.8%가 관측되어 경계가 가깝다. 임계값을 낮추기만 하면 오경고가 늘 수 있다.
- 다리 경고는 각 동작에서 짧게 발생. 일반 사용자를 대상으로 지속시간·단계 감지 성능을 더 평가해야 함.
- 같은 한 사람의 오류 3회/정상 3회로 개발 확인. 사람을 분리한 독립 평가가 아니며 임상적 정확도·일반화 확인 불가.
- Point 영상은 세부 시간별 정답 미확정이므로 경고 위치만 검토 가능.
- 측면에 가까운 고정 구도 전제. 화면 위쪽과 실제 수직의 원근 차이는 남음.

## 수치와 근거 구분
다리 높이 = (골반 y − 발목 y) / 준비 몸통 길이(없으면 현재 길이), 후보 0.08 초과.
몸통 이동 = 지지 관절 기준 어깨/골반 이동 중 큰 값 / 준비 몸통 길이, 후보 0.12 초과.
몸통 기울기 변화 후보 12° 초과. 이동 또는 기울기 조건이 0.25초 이어지면 경고.
몸통 안정·과도한 다리 들기 제한은 운동 자료의 원칙이다. 위 숫자와 단계 경계는 모두 구현 후보이며 논문의 검증값이 아니다.
