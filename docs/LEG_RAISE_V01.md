# 레그 레이즈 v0.1

현재 `leg-raise-0.1.1`에는 [템포 관측값](LEG_RAISE_TEMPO.md)이 추가되어 있습니다. 아래 카운트·판정 기준과 공통 결과 v2는 유지합니다.

바닥에 누워 양다리를 함께 올리고 내리는 **다리를 편 레그 레이즈**를 측면에서 분석합니다. MediaPipe Full의 어깨·골반·무릎·발목 중 보이는 한쪽을 사용합니다. 기존 운동의 판정 규칙은 변경하지 않았습니다.

## 자료와 적용 범위

| 자료 | 확인한 내용 | 구현에 반영한 부분 |
|---|---|---|
| [University of the Incarnate Word / MedBridge 운동 안내, p.2](https://my.uiw.edu/wellness/_docs/w-corestability1.pdf) | 누운 자세에서 무릎을 편 채 양다리를 들고 내리며 허리 과신전을 피하는 방법 | 다리를 편 운동 변형을 명시하고 무릎 펴기를 관찰합니다. 문서의 작은 다리 들기를 보편적인 90도 목표로 바꾸지 않았습니다. |
| [Selhorst 등, IJSPT 2020, Figure 6](https://pmc.ncbi.nlm.nih.gov/articles/PMC7134351/) | 양다리를 내리는 검사에서 허리와 지지면 접촉이 사라지는 시점을 관찰합니다. | 허리 접촉은 중요한 요소지만 일반 관절 좌표에는 해당 측정점이 없어 판정하지 않습니다. 재활 검사의 각도 기준을 일반 사용자 운동 임계값으로 옮기지 않았습니다. |
| [Muscle & Strength 공식 운동 안내](https://www.muscleandstrength.com/exercises/lying-floor-leg-raise.html) | 다리를 펴고 올린 뒤 천천히 내리는 시범 | 하강 시간·각속도를 기록하고 빠른 하강을 피드백합니다. |

자료는 운동 원칙의 근거입니다. 아래 수치들은 임상적으로 검증된 정상/비정상 경계가 아니라 영상 기반 초기 구현값입니다.

## 판정 항목

| 항목 | 계산과 조건 | 출력 |
|---|---|---|
| 무릎 펴기 | 선택한 쪽 골반–무릎–발목 각도. 155° 미만이 250ms 이상 지속 | `knee_extension` / `KNEE_BENT` |
| 하강 속도 | 평활화된 다리 각도의 최고점부터 복귀 판정까지. 1.1초 미만이며 평균 각속도 80°/s 초과인 경우 | `lowering_control` / `LOWERING_FAST` |
| 허리–바닥 접촉 | 현재 33점 입력으로 직접 측정할 수 없음 | `lumbar_contact: not_supported`; 세트 집계는 `unknown`, 준수율 `null` |

`lowering_control`은 빠른 하강만 확인하는 대리 지표입니다. 이 항목이 준수 상태여도 반동·근육 활성·허리 정렬이 모두 정상이라는 뜻은 아닙니다. 굽힌 무릎 변형에서는 `KNEE_BENT`가 발생할 수 있으며, 이는 다리를 편 운동 규격과의 차이입니다. 변형 운동 자체가 잘못됐다는 의미는 아닙니다.

## 카운트와 단계

`not_ready → ready → raising → lowering → ready`

- 보이는 쪽을 선택해 유지합니다. 해당 쪽을 300ms 이상 사용할 수 없고 반대쪽이 확보되면 전환하며 진행 중 왕복 기록은 끊습니다.
- 몸통 화면 기울기 35° 이하, 필요한 네 관절의 visibility/presence 0.5 이상을 관측 조건으로 사용합니다. 자동 운동 종목 분류기가 아닙니다.
- 다리 들림 값은 `180° − ∠(어깨, 골반, 무릎)`입니다. 픽셀 좌표로 계산해 영상 종횡비를 반영합니다. 실제 지면과 이루는 3차원 각도는 아닙니다.
- 최근 낮은 위치에서 25° 이상 올리고, 최고점에서 내려와 시작 각도 +12° 이내로 돌아오면 1회입니다. 반전 확인은 8°, 최소 왕복 시간은 650ms입니다. 절대 최저각이나 90° 도달을 강제하지 않습니다.
- 이미 올라간 채 시작하는 클립은 처음의 불완전한 하강만으로 횟수를 만들지 않습니다. 완전한 올림–내림이 관측돼야 합니다.
- 무릎/속도 경고는 횟수를 취소하지 않습니다. 관절 손실, 일시정지, 300ms 초과 입력 공백은 미완료 동작을 끊습니다.
- 허리 들림·호흡·복부 근육 활성·반대쪽 가려진 다리는 판정 범위에 포함하지 않습니다.

## 공통 결과 규격

`LegRaiseAnalyzer.pushFrame()`, `breakContinuity()`, `summary()`, `finish()`를 제공합니다.

| 필드 | 레그 레이즈 의미 |
|---|---|
| `schemaVersion` / `exercise` | `2.0` / `leg_raise` |
| `count` / `measurementBasis.count` | 관측된 올림–내림 왕복 수 / `completed_raise_lower_attempt` |
| `holdSeconds` | `null` |
| `observedSeconds` | 필요한 관절과 누운 몸통 방향이 연속 관측된 시간. 세션 전체 시간과 다릅니다. |
| `items` | 현재 무릎 상태, 회차 대기 중인 하강 속도, 허리 판정 미지원 |
| `lastRepetition` | 최근 회차 항목·경고·측정값, 표시 기간 1.8초 |
| `metrics` | 무릎 각도·다리 들림·몸통 기울기·선택한 관절 ID |
| `summary.items` | `aggregationBasis: repetition`, `unit: repetitions`, 준수율 0–100 또는 `null` |
| `summary.details` | 회차별 시작·최고점·끝 시각, 하강 시간·각속도, 설정, 운동 변형, 미지원 항목 |

허리 접촉을 준수율 분모에 넣지 않습니다. `not_supported`를 정상으로 표시하지 않습니다. 현재 경고와 최근 회차 피드백은 기존 v2 규격대로 분리합니다.

## 검증 자료 관리

분석 결과와 영상은 `output/leg_raise_20261023/`에 저장합니다. 원본 출처·구간은 `cases.json`과 `sources_manifest.json`, 항목별 수치는 `validation.json`, 프레임·세트 결과는 각 `cases/<id>/results/`에서 확인합니다. 외부 영상은 저장소에 포함하지 않습니다.

검증 구간의 선정과 수치 보정에 같은 자료를 사용한 개발 검증입니다. 정상/오류 시범은 게시자의 설명과 영상 관찰을 바탕으로 구분했으며 전문가 독립 라벨이나 전체 사용자 대상 정확도 평가가 아닙니다. 같은 영상의 재생 반복·화면 확대 장면은 별도 사람/독립 표본으로 세지 않습니다.

무릎 155°/250ms는 일시적인 추적 흔들림과 약간의 굽힘을 허용하는 시작값입니다. 초기 정상 시범의 순간 최소 각도는 약 158–169°, 오류 시범은 약 143–151°였습니다. 하강 속도 경계는 초기 정상의 약 30–52°/s와 오류의 약 89–106°/s 사이에서 정했습니다. 같은 자료로 보정·확인한 결과이므로 일반화 성능 수치로 사용하지 않습니다.

추가 Muscle & Strength 시범은 기준을 고정한 후 확인했습니다. 관측된 무릎 굽힘은 영상에서도 보이지만 게시자가 정상 시범으로 제시했으므로, 해당 경고를 곧바로 잘못된 운동의 확정 판정으로 해석할 수 없습니다. 현재 범위는 다리를 편 변형의 형태 확인과 빠른 하강 안내입니다.

실시간 결과 1,269개·세트 결과 7개를 v2 Schema로 검사하고 회차 합계와 준수율을 별도 재계산했습니다. JavaScript 테스트 79개가 통과했습니다. 분석 영상은 원본 재생 속도를 유지하고 영어로 관절·횟수·경고를 표시합니다.

### 기준 고정 후 추가 영상 검증

[추가 검증 기록](LEG_RAISE_EXTERNAL_VALIDATION_20261023.md): 다른 3명의 영상 6개 구간에서 육안으로 확인한 완전 왕복 16회와 카운트 16회가 일치했습니다. 실시간 결과 1,305개·세트 결과 6개가 공통 v2 Schema 검사를 통과했습니다. 다리를 편 시범 13회에서 회차 무릎 경고는 없었고, 빠른 하강 경고는 1회 발생했습니다. 하강 1.068초로 경계값에 가까운 사례이며 템포 안내로 해석합니다. 준비·종료 시 누운 채 무릎을 접는 경우에도 실시간 경고가 나올 수 있으며, 완료 회차 평가에는 포함되지 않았습니다. 판정 로직과 임계값은 변경하지 않았습니다.
