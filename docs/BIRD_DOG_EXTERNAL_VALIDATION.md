# 버드독 v0.2 · 새 영상 검증

2026-10-20. 새 수행자 4명, 출처 4개, 총 7구간. 기존 Elite/Point 결과는 이번 새 표에 포함하지 않았다.

## 결론
오류 시범에서는 경고가 발생했지만, 새로운 정상 시범에서도 경고가 반복됐다.
현재 8%/12%/12° 기준을 그대로 일반 사용자에게 적용할 준비가 됐다고 볼 수 없다.
기존 한 사람의 정상에서 경고가 없던 결과가 다른 사람에게 그대로 반복되지 않았다.

## 고정한 조건
- MediaPipe Pose Landmarker Full, 영상 입력 → 33관절 → 기존 bird-dog-experimental-0.2.
- 다리 높이 8%, 몸통 이동 12%, 기울기 변화 12°, 경고 지속 0.25초. 수치를 변경하지 않음.
- 기존 추출기의 최대 가로 960px/목표 15fps 사용. 원본 프레임률에 따라 실제 표본 간격은 달라진다.
- 구간별 별도 실행. 각 구간 앞 준비 장면으로 자동 기준을 확보하며 미래 프레임을 사용하지 않음.
- 로직 파일을 복사하고 SHA256 기록. 검증 종료 시 코드 해시 동일 확인.
- 무릎 등 나머지 항목은 비활성. 허리 곡률과 축 방향 회전은 지원하지 않음.

## 구간 선택
모델 결과를 보기 전에 `annotations_before_inference.json`에 구간을 기록했다.
원본 프레임을 확인하고, PostureDoc/Titan은 공개 자동 자막을 함께 대조했다.
정상/오류는 출처가 설명한 시범 의도와 육안 확인에 따른 검토 라벨이며, 독립 전문가가 프레임마다 부여한 임상 정답이 아니다.
설명·자세 준비·전환을 포함한 전체 분석 영상과, 통계에 사용한 평가 구간을 구분했다.

| 구간 | 원본에서 평가한 시간 | 선택 근거 |
|---|---|---|
| E3 정상 | 0.5–18.5초 | 기본 운동 시범, 전신을 볼 수 있음 |
| Vissco 정상 | 3.2–16.2초 | 운동 안내 시범, 초기 앉은 자세/설정 제외 |
| PostureDoc 오류 | 164–173.5초 | 설명자가 흔한 실수로 소개. 다리를 과하게 들고 몸통 지지가 무너지는 시범 |
| PostureDoc 교정 | 214–220초 | 지지면을 밀고 팔다리를 길게 뻗도록 설명한 교정 시범 |
| Titan 정상 | 54–75초 | 물리치료사가 좋다고 평가한 양쪽 시범 |
| Titan 오류 | 97–101.5초 | 치료사가 피해야 할 골반 들림/기울임을 설명한 시범 |
| Titan 후반 | 130–147, 152–158초 | 좋은 수행 평가, 한쪽 약함, 어깨 처짐 교정이 섞임. 탐색용이며 이진 성능 집계 제외 |

## 선정 구간 결과

| 구간 | 평가 길이 | 다리 높이 경고(좌우 합계) | 몸통 경고 |
|---|---:|---:|---:|
| e3_normal | 18.00초 | 2.40초 | 6.67초 |
| vissco_normal | 13.00초 | 0.25초 | 2.25초 |
| posture_error | 9.50초 | 8.92초 | 8.17초 |
| posture_corrected | 6.00초 | 0.17초 | 0.00초 |
| titan_normal | 21.00초 | 2.33초 | 6.87초 |
| titan_error | 4.50초 | 1.13초 | 0.93초 |

위 수치는 경고 시간이지 정확도/오류율이 아니다. 다리 평가는 유지 단계만 대상이다.
`evaluation.json`과 CSV에 관측 가능·관측 불가·단계 제외 시간을 따로 기록했다.
새 정상·교정 구간 4개 모두에 다리 경고가 한 번 이상 발생했고, 이 중 E3/Vissco/Titan 정상 3개에서는 몸통 경고도 발생했다.
이는 출처의 정상 시범 기준 오경고 후보이며 개인의 자세가 완벽하다는 인증은 아니다.
선정한 두 오류 구간 모두에서 다리 높이·몸통 경고가 발생했다. Titan의 회전 오류 자체를 인식했다고 해석하지 않는다.

## 영상과 측정값에서 확인한 내용
1. **E3 정상:** 첫 몸통 경고 시작 시 기울기 변화 약 1.0°인데 이동량 19.4%로 경고. 따라서 이 경고를 척추 정렬 붕괴로 해석할 수 없음. 자연스러운 체중 이동과 2D 투영/관절 추적 영향을 분리해야 한다.
2. **Vissco 정상:** 몸통 경고 시작 시 이동량 16.7%, 기울기 변화 4.6°. 다리 높이 경고는 마지막 동작에서 0.25초 발생. 지속적인 잘못된 자세와 짧은 경계 초과를 구별해야 한다.
3. **PostureDoc:** 명확한 오류 시범의 다리 경고 시작 시 높이 비율 약 56.6%, 교정 구간의 짧은 경고에서는 약 10.6%. 뚜렷한 오류는 잡지만 8% 근처 정상/교정 시범도 경고할 수 있다.
4. **Titan:** 정상 시범부터 몸통·다리 경고가 발생. 기울어진 시점과 지도자가 함께 있는 구도다. 확인한 대표 오버레이는 수행자를 추적하지만, 전 프레임 동일 인물 추적을 별도 검증한 것은 아님. 원근/가림/좌표 영향이 섞여 있으므로 임계값 하나만의 문제로 단정하지 않는다.
5. **평가 한계:** 다리 경고가 유지 단계에만 나오므로 오류 구간의 다른 단계에서 경고가 없다고 모두 누락으로 계산하면 안 된다. 회전·허리 곡률·어깨 처짐 같은 미지원 항목도 별개다.

## 다음 보완의 우선순위 (이번 실행에서 변경하지 않음)
- 다리 높이: 화면 y축만의 차이를 촬영 구도/몸통 방향과 분리하는 방법 검토. 정상·오류 양쪽을 유지한 상태로 비교할 것.
- 몸통 움직임: 자연스러운 체중 이동과 제어 실패를 구분. 지지점 선택의 연속성·실제 지지 여부, 기준점 품질부터 확인.
- 준비·뻗기·유지·복귀 상태도 독립 검토. 상태 오인식과 높이 규칙 오류를 분리.
- 이번 새 영상들은 이제 검토에 사용했으므로, 이후 임계값을 조정하면 최종 평가는 다른 사람의 영상으로 수행.

## 산출물
- `index.html`: 원본 시간 표시·선정 구간·경고 직전 이동 버튼이 있는 분석 영상 모음.
- `annotations_before_inference.json`: 모델 실행 전 선정 구간.
- `evaluation.json/csv`: 선정 구간만의 경고·관측 시간.
- `warning_events.json`: 전체 분석 구간의 경고 타임라인.
- `results/*/frames.jsonl`, `summary.json`, `overlay.mp4`: 프레임별 결과, 전체 구간 요약, 분석 영상.
- `engine_hashes.json`: 고정 로직 SHA256. 각 추출 캐시에 영상/모델 SHA256과 추출 설정 보존.
- 모든 분석 MP4를 끝까지 디코딩하여 결과 행 수와 일치함을 확인했다.
영상 파일은 저장소에 커밋하지 않는다. 이번 작업에서 판정 규칙이나 임계값을 수정하지 않았다.
