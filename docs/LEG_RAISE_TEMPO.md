## 측정 방법

평활화된 다리 각도를 최근 250ms 구간에서 직선 회귀하여 각속도를 구합니다. 최소 관측 길이는 120ms입니다. 각속도 절댓값 4°/s 이하가 300ms 이상 지속되면 정지로 기록합니다. 최고점·최저점 위치 구분에는 해당 회차 최대·최소 각도의 5° 이내 구간을 사용합니다. 이 수치는 관측 노이즈를 구분하는 초기 공학 설정이며 운동의 정상/오류 기준이 아닙니다.

실시간 측정은 미래 프레임을 사용하지 않습니다. 정지 확인에는 관측 지연이 있으며, 확인된 구간은 후보가 시작된 시점부터 누적합니다. 회차 종료 후에는 해당 구간을 정리해 시간 합계를 반환합니다. 짧고 불확실한 정지는 임의로 상승·하강 또는 유지 시간에 합치지 않습니다.

`상승 움직임 + 하강 움직임 + 정지 + 분류 보류 = 회차 구간 시간`

`최고점 유지 + 최저점 유지 + 중간 정지 = 전체 정지 시간`

## 해석 범위

- `topHoldMs`는 관측된 최고점 부근 유지 시간입니다. 근육 수축·복부 힘·운동 효과를 직접 측정한 값은 아닙니다. 특정 목표 각도 도달 여부도 의미하지 않습니다.
- 회차 측정 범위는 기존 카운트 구간과 같습니다. 복귀 허용 범위에 들어오면 카운트가 끝나므로, 이후 최저점까지 남은 이동이나 다음 회차 전 휴식은 완료 회차 합계에 포함되지 않습니다. 그동안의 움직임·정지는 실시간 값에서 계속 관측합니다.
- 낮은 위치에서 준비·휴식하는 시간도 실시간 정지로 보일 수 있습니다. 운동 의도나 프론트 세션 상태를 자동 판별하는 기능은 추가하지 않았습니다.
- 기존 `loweringDurationMs`는 최고점 시각부터 복귀 판정까지의 시간으로 보존했습니다. 정지가 섞일 수 있는 기존 판정용 시간입니다. 새 `lowerMovingMs`는 실제 하강으로 분류된 시간이며, 두 값은 서로 다른 의미입니다. `LOWERING_FAST`는 기존 값을 그대로 사용합니다.
- 느린 움직임과 정지를 구분하는 데 2D 관절 추적과 샘플링 오차가 있습니다. 수치는 추정값이며 분석 영상의 장면과 함께 확인합니다.
