## 실제 확보한 자료

QEVD 공식 라벨 및 분할 압축파일에서 19개 샘플과 원본 라벨·출처를 저장했다. 전체 데이터셋은 받지 않았다.
라벨별 수는 중복 가능한 영상 수이며, 독립 사람 수나 검수 완료 영상 수가 아니다. average는 전문가가 검증한 정석 자세 라벨과 같지 않다.
점핑잭 정상 후보는 arms_rom=4.0 및 legs_rom=3.0 교집합에서 명시적 동작 문제 라벨을 제외한 자체 선별 결과다.
샘플 프레임 검토에서 역광·신체 잘림이 확인됐으므로 본 분석 전 전체 클립을 검수해야 한다.

우선 볼 버드독: bird_dog_normal_86.mp4, bird_dog_normal_172.mp4, bird_dog_drop_82.mp4, bird_dog_drop_165.mp4.

## YOLO와 MediaPipe 실제 실행

- MediaPipe Pose Landmarker Full과 YOLO11n-pose(경량 후보)를 기존 Mendeley 2번·5번 사람의 정상·오류 측면 영상 4개에 실행.
- 총 513개 입력 프레임을 각 모델에 적용. CPU 실행, 약 5fps 표본 추출, 입력 가로 640px, Torch 4스레드.
- 전체 화면 1차 실행에서는 YOLO가 배경 사람을 선택하는 경우 발견. 모델 자체의 관절 정확도와 대상 선택 문제를 분리해야 함.
- 2차는 두 모델에 동일한 수동 운동 영역 적용: 2번은 화면 아래 60%, 5번은 아래 75%. YOLO는 가장 큰 사람 박스 선택. 자동 대상 선택의 해결을 의미하지 않음.
- 공통 12개 2D 관절만 비교. 카운트·피드백 판정 로직은 연결하지 않았음.

| 항목 | MediaPipe Full | YOLO11n-pose |
|---|---|---|
| 영상별 중앙 처리 시간 | 약 12.1~12.2ms | 약 13.6~16.2ms |
| 관절 출력 | 33개, 깊이·가시성 등 | 17개 2D 관절과 confidence |
| 샘플 관찰 | 가려진 반대쪽 관절은 불확실 | 일부 장면에서 팔·골반·다리 좌표가 어긋나거나 누락 |

속도는 디코딩·입력 리사이즈·화면 표시를 제외하고 추론 및 좌표 추출을 잰 값이다. 최초 5프레임 제외. 모바일 속도나 앱 전체 지연이 아니다. MP와 Torch 스레드 설정도 완전히 통제되지 않았으므로 정식 순위표가 아니다.
confidence 0.5는 표시용 임시 기준이다. MP의 visibility/presence와 YOLO confidence는 의미가 달라 관절 표시율을 정확도로 비교하면 안 된다. 수동 정답 좌표가 없으므로 정확도 우열을 확정하지 않는다.
YOLO 출력에 없는 깊이를 임의 생성하거나 confidence를 MP 가시성으로 간주해서 기존 판정기에 바로 넣지 않는다.
