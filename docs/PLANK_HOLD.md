# 플랭크 정상 판정 유지 시간

## 변경 범위

기존 `holdSeconds`에 골반·어깨·무릎 항목이 모두 정상으로 판정된 누적 초를 제공한다. 프레임·세트 JSON의 필드 구조, 자세 판정 임계값, 경고 코드, 준수율 계산은 유지한다. `count`는 여전히 null이다.
프론트 시작 신호 연동이나 자동 세트 종료는 구현하지 않는다. 이 모듈에 전달된 프레임 구간만 분석한다.

## 누적 기준

- 선택된 한쪽의 수행 형태가 확인되고, 골반·어깨·무릎 세 항목이 모두 `within_reference`일 때만 누적한다. 앞뒤 샘플 모두 이 조건을 만족하고 선택된 쪽이 같아야 시간 간격을 더한다.
- 세 항목 중 하나라도 경고·안정화 중·관측 불가이면 누적을 멈춘다. 정상으로 복귀하면 기존 누적값에서 이어간다. 기존 경고 지연·해제 기준과 임계값을 그대로 사용하며, 판정이 확정되기 전의 실제 자세 이상을 별도로 소급 판정하지 않는다.
- 몸 방향·지지 형태가 확인되지 않거나 필수 관절이 가려지면 누적을 멈춘다. 이미 누적한 시간은 보존한다.
- 수행 형태 확인은 연속 0.3초가 필요하다. 이후 기존 자세 판정의 안정화까지 완료되어야 정상 유지 시간이 시작된다. 준비·안정화·오류 구간은 정상 유지 시간에 소급해서 넣지 않는다.
- 샘플 간격이 0.25초를 넘거나 좌우가 전환되거나 `breakContinuity()`가 호출되면 구간을 끊는다. 공백은 채워 넣지 않는다. 이후 다시 관측된 구간만 누적한다.
- 마지막 프레임 이후의 시간은 추정해서 더하지 않는다. `finish()`는 이미 관측한 누적값을 반환한다.

`observedSeconds`는 기존 연속 입력 샘플 시간이고, `holdSeconds`는 그중 현재 판정 기준상 세 항목을 모두 준수한 시간이다.

비율은 `100 * holdSeconds / observedSeconds`로 계산할 수 있다. 분모 0이면 null이다. 준비·평가 불가 구간도 연속 관측 중이었다면 분모에 포함된다. 긴 입력 공백과 명시적 일시정지는 기존처럼 분모에서도 제외한다. 따라서 이 비율은 전체 벽시계 시간 기준이 아닌 **연속 관측 시간 대비 정상 유지 비율**이다. 항목별 준수율의 평균과도 다르다. JSON 필드를 추가하지 않고 기존 두 값으로 계산한다.

## 내부 관측 조건

시간 계산 전용 조건이며 자세의 정석·오류 임계값이 아니다. 측면의 수평 카메라를 전제로 한 공학적 초깃값이다.

| 조건 | 값 |
|---|---|
| 필요한 관절 visibility / presence | 각각 0.5 이상, 화면 안에 위치 |
| 어깨→발목의 수평 성분 / 길이 | 0.65 이상 |
| 어깨보다 팔꿈치가 아래에 있는 거리 / 어깨→발목 길이 | 0.035 이상 |
| 어깨→발목 길이 / 어깨→팔꿈치 길이 | 2.0 이상 |
| 팔꿈치→손목의 수직 성분 / 길이 | 0.65 이하 |
| 골반의 어깨→발목 축 투영 | 두 끝점 사이 |

이 내부 조건은 수행 형태만 확인한다. 실제 `holdSeconds`에는 기존 골반·어깨·무릎 판정까지 모두 정상인 구간만 더한다. 무릎 가림도 정상 여부를 확인할 수 없으므로 누적을 보류한다.

## 확인 결과와 한계

- 기존 9개 영상 2,533프레임: holdSeconds와 엔진 버전을 제외한 프레임 결과, 세트 항목별 집계·준수율 동일.
- Python/JavaScript의 정상 유지 시간 일치. 경고·판정 보류 구간에서는 증가하지 않음.
- P1: 정상 유지 2.667초 / 관측 15.267초. P2: 14.933초 / 15.333초. 무릎 굽힘 확인용 E2: 8.399초 / 25.933초. E3는 필수 관절 신뢰도 부족으로 0초(관측 보류).
- 서 있음·하이 플랭크·좁게 무릎을 꿇은 자세·가림·일시정지·시간 공백·좌우 전환은 합성 좌표로 확인했다. 실제 다양한 준비·종료 영상에 대한 정확도 평가를 완료한 것은 아니다.
- 2D 좌표만 사용하므로 바닥 접촉, 엎드린 휴식과 유사 자세, 크게 기울어진 카메라는 추가 검증 대상이다. 이 값은 관측 가능한 수행 시간이며 물리적인 지지 여부를 보장하지 않는다.
