# 현재 판정 기준

## 푸시업

기준 파일: `runtime/pushup/config.js`, Python 참조: `analysis/pushup/reference.json`.
별도의 정상 영상을 매번 입력하지 않는 공통 기준입니다.

- 카운트: 팔꿈치 또는 어깨 이동 신호의 내려감→복귀를 감지하고 같은 움직임의 이중 신호를 합칩니다.
- 카운트와 자세 평가를 분리합니다. 얕은 움직임도 노이즈·시간 조건을 충족하면 카운트하고 굽힘 부족을 피드백합니다.
- 골반: 어깨–발목 직선 대비 골반의 부호 있는 거리(%).
- 팔꿈치: 어깨–팔꿈치–손목의 2D 굽힘. `ELBOW_SHALLOW`가 벌어짐을 직접 측정하는 것은 아닙니다.
- 상체 이동: 어깨와 손목의 화면상 높이 차 변화. 실제 가슴 이동의 대리값입니다.
- 손 위치: 몸통 방향으로 투영한 상대 손목 위치. 실제 가슴 중앙을 추정하는 모델은 아닙니다.
- 복귀: 되올라오는 구간의 팔꿈치 펴짐.

핵심 오류 코드: `HIP_DROP`, `HIP_RAISE`, `ELBOW_SHALLOW`, `CHEST_RANGE_LOW`,
`RETURN_INCOMPLETE`, `HAND_TOWARD_HEAD`, `HAND_TOWARD_HIP`.
앱용 좌우 선택은 같은 쪽 어깨·팔꿈치·손목·골반·발목이 1초 안정적으로 관측되는지 확인합니다.
선택한 쪽이 1초 이상 불량하고 반대쪽이 안정적이면 전환하며 미완성 움직임은 끊습니다.

## 플랭크 — 일반 팔뚝 플랭크의 측면 후보 기준

| 항목 | 경고 진입 | 해제 | 단위 |
|---|---:|---:|---|
| 골반 처짐 | >4 | ≤3 | 어깨–발목 길이 대비 % |
| 골반 올라감 | <−12 | ≥−10 | 어깨–발목 길이 대비 % |
| 어깨–팔꿈치 정렬 | >20 | ≤15 | 화면 수직 방향과의 각도(도) |
| 무릎 펴기 | <160 | ≥165 | 골반–무릎–발목 각도(도) |

0.3초 중앙값 필터, 0.4초 워밍업, 0.6초 경고 지속, 0.4초 해제 지속.
0.25초 초과 프레임 간격이면 연속 판정 상태를 초기화합니다.
좌우 선택은 어깨·골반·발목 품질로 정하고 선택한 쪽이 0.4초 관측되지 않으면 반대쪽을 검토합니다.
이후 어깨–팔꿈치, 골반–무릎–발목은 항목별로 유효성을 판단합니다.
현재 한쪽 무릎을 관측하므로 반대쪽만 굽힌 사례는 놓칠 수 있습니다.

골반 부호는 화면 아래 방향이 양수입니다. 실제 중력/3D 척추 중립을 측정하는 값은 아닙니다.
어깨 정렬은 수평이 맞는 측면 카메라를 전제로 합니다. 장축 플랭크·무릎 플랭크 등 변형 운동은 별도 종목입니다.
팔꿈치 90도는 설명상의 참고이며 현재 판정 임계값으로 사용하지 않습니다.

## 보존 범위

이번 저장소 정리는 기준 수치나 카운트 정책을 바꾸지 않았습니다.
Python 플랭크에서 화면 표시 코드에 있던 거리 계산 함수만 분리했고, 공통 출력 어댑터를 추가했습니다.
신뢰도 값만 높다고 실제 관절 위치가 정확한 것은 아닙니다. 전신 노출/준비/종료 감지는 별도로 보완해야 합니다.
