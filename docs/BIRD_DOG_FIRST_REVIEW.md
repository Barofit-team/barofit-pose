- 임시 임계값으로 3구간 총 722프레임 분석. 원본 라벨 관절을 사용하지 않음.

## 전문가 시범 비교

Elite Physical Therapy 출처는 앞 3회 오류, 뒤 3회 정상으로 설명한다.
오류 0–7.5초, 정상 10–17.6초를 독립 분석했다. 같은 사람·같은 영상이므로 일반화 성능 검증은 아니다.

| 지표 | 오류 시범 | 정상 시범 |
|---|---:|---:|
| 분석 프레임 | 113 | 114 |
| 뻗기 후보 구간 오른쪽 다리 각도 중앙값 | +11.0° | −20.6° |
| 뻗기 후보 구간 왼팔 각도 중앙값 | −6.1° | −32.0° |
| 오른쪽 무릎 펴기 경고 시간 | 1.33초 | 1.47초 |

팔다리 각도는 화면 수평 기준이며 위쪽 양수다. 실제 해부학적 각도/바닥 보정 완료 각도가 아니다.
뻗기 후보에는 전환 과정도 포함된다. 회당 최고점끼리 맞춘 값은 아니며 프레임 수를 독립 표본 수로 보지 않는다.
정상에서는 팔다리를 낮게 뻗고 오류에서는 높이 드는 차이가 보이지만, 한 사람의 값으로 공통 임계값을 정하지 않았다.

## 발견한 한계

1. 155° 미만 무릎 경고가 정상으로 소개된 구간에도 발생했다. 오경고 후보이며 제품 기준으로 채택하지 않는다.
2. 전문가가 강조한 주된 오류인 허리 과신전은 직접 검출하지 못한다. MediaPipe에 요추 곡률 관절점이 없다.
3. 팔다리 각도 차이는 보조 신호가 될 수 있지만 허리 오류의 증명은 아니다. 20° 높이 경고도 이번 오류 구간에서는 지속 경고가 발생하지 않았다.
4. Point Performance 20–53초에서는 총 495프레임에 왼쪽 무릎 펴기 경고 약 2.07초. 세부 정상/오류 시간 라벨이 없으므로 정확도/오경고율을 계산하지 않았다.
5. 좌우 가림, 원근, 수행 단계에 따라 관측 가능성이 다르다. unknown과 not_supported는 정상으로 집계하지 않았다.
6. 0.35초 뒤 평가 방식은 실제 끝점 감지가 아니다. 뻗기 끝점과 복귀를 더 명확히 나누는 개선이 필요하다.

## 결론

문헌 기반 판정 항목을 실행 가능한 실험 모듈로 만들었고 전문가 시범에 적용했다.
아직 정상과 오류를 안정적으로 분리하는 완성 모듈은 아니다.
다음은 팔다리 뻗기 끝점 검출과 무릎 경고의 적용 조건을 먼저 보완하고,
허리 곡률을 측정했다고 주장하지 않는 범위에서 몸통/골반 변화 대리지표를 검토한다.
임계값은 전문가 시범 한 영상에 맞추지 않고 다른 인물과 구도에서 검증해야 한다.
